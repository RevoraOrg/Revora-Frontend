# Transaction Receipt Print Template

## Purpose
Provides a printable A4 transaction receipt for PDF export and physical printing.

## Features
- A4 print layout
- Letter paper support
- WCAG 2.1 AA considerations
- Responsive design
- Explorer URL
- Transaction hash
- Print-friendly styling

## Accessibility
- Semantic headings
- High contrast
- Screen-reader friendly labels
- Print controls hidden during printing

## Print Behaviour
- Uses @media print
- Avoids page breaks inside receipt
- Optimized for monochrome printers

## Edge Cases
- Long transaction hashes
- Long wallet addresses
- RTL languages
- Large descriptions
